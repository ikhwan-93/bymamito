# Bymamito Bakery Website — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a classy single-app website for a homemade bakery with a public storefront (categorized menu + cart + WhatsApp ordering) and a password-protected admin (CRUD for categories, products, posts, settings).

**Architecture:** Next.js App Router with TypeScript, Prisma + SQLite for persistence, Tailwind for styling. Public pages read data server-side; cart is client-side (localStorage) and checkout opens `wa.me` with a pre-filled message. Admin uses a signed session cookie and server actions for CRUD.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Prisma + SQLite, Tailwind CSS 3, `jose` (JWT session cookie), `bcryptjs` (password hashing), `zod` (validation).

## Global Constraints

- Node >= 20; npm package manager.
- All currency is Malaysian Ringgit (RM); prices stored as integer cents.
- WhatsApp number stored in Settings as digits only, e.g. `194712426295357`.
- Copy language: English.
- Never commit `.env`; provide `.env.example`.
- No comments in code unless necessary.
- Product images upload to `public/uploads/`.

- [ ] **Step 2: Write the seed script**

Create `prisma/seed.ts`:
```ts
import { PrismaClient } from "@prisma/client";

const prisma = new PrismaClient();

async function main() {
  const categories = [
    { name: "Cakes", slug: "cakes", sortOrder: 1 },
    { name: "Cookies", slug: "cookies", sortOrder: 2 },
    { name: "Pastries", slug: "pastries", sortOrder: 3 },
  ];

  for (const c of categories) {
    await prisma.category.upsert({
      where: { slug: c.slug },
      update: {},
      create: c,
    });
  }

  const cakes = await prisma.category.findUnique({ where: { slug: "cakes" } });
  if (cakes) {
    await prisma.product.upsert({
      where: { id: 1 },
      update: {},
      create: {
        id: 1,
        name: "Chocolate Fudge Cake",
        description: "Rich, moist chocolate cake.",
        priceCents: 4500,
        available: true,
        categoryId: cakes.id,
      },
    });
  }

  await prisma.post.upsert({
    where: { id: 1 },
    update: {},
    create: {
      id: 1,
      title: "Welcome to Bymamito",
      body: "Fresh homemade bakes, made with love.",
      published: true,
    },
  });

  const defaults: [string, string][] = [
    ["whatsapp_number", "194712426295357"],
    ["business_hours", "Open daily, 9am - 6pm"],
    ["about_text", "Bymamito is a homemade bakery."],
    ["instagram_url", "https://www.instagram.com/bymamito/"],
  ];

  for (const [key, value] of defaults) {
    await prisma.setting.upsert({
      where: { key },
      update: {},
      create: { key, value },
    });
  }

  console.log("Seed complete");
}

main()
  .catch((e) => {
    console.error(e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

- [ ] **Step 1: Write settings helpers**

Create `src/lib/settings.ts`:
```ts
import { prisma } from "./prisma";

export async function getSettings(): Promise<Record<string, string>> {
  const rows = await prisma.setting.findMany();
  return Object.fromEntries(rows.map((r) => [r.key, r.value]));
}

export async function getSetting(key: string, fallback = ""): Promise<string> {
  const row = await prisma.setting.findUnique({ where: { key } });
  return row?.value ?? fallback;
}
```

- [ ] **Step 2: Write the currency formatter**

Create `src/lib/format.ts`:
```ts
export function formatRM(cents: number): string {
  const rm = (cents / 100).toFixed(2);
  return `RM ${rm}`;
}
```

- [ ] **Step 3: Write the WhatsApp link helper**

Create `src/lib/wa.ts`:

```ts
export function whatsappLink(number: string, message: string): string {
  return `https://wa.me/${number}?text=${encodeURIComponent(message)}`;
```
